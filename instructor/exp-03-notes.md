# Instructor Notes — Experiment 3

## Prep (30 min, plus source paperwork)

- Sign out the $^{90}$Sr/$^{90}$Y source and confirm the inventory log.
- Check the aluminium absorber set is complete and that the labelled mass
  thicknesses are right. Weigh a few; foils get swapped between kits.
- Confirm the GM tubes' plateaus and note the correct operating voltages on
  each counter. A tube driven above plateau is destroyed in minutes.
- Pull the tube data sheet for the mica window mass thickness
  ($\sim1.5$–$2\ \text{mg/cm}^2$ typical).

## Bill of materials

| Item | Have | Note |
|---|---|---|
| GM counter + thin end-window tube | ✓ | Several |
| $^{90}$Sr/$^{90}$Y sealed source | ✓ | ~1 µCi |
| Al absorber set to 1200 mg/cm² | ✓ | Verify annually |
| $^{204}$Tl source | ? | Only for the extension |
| Source tongs, shelf stand | ✓ | |

## Expected results

- Maximum range: Feather's rule gives $R_m = 1.10\ \text{g/cm}^2 =
  1103\ \text{mg/cm}^2$ for $T_{\max} = 2.28\ \text{MeV}$; Katz–Penfold gives
  $1095\ \text{mg/cm}^2$. Agreement here is better than usual — do not let
  students conclude the two relations always agree.
- $4.1\ \text{mm}$ of aluminium. Confirm the absorber set actually reaches
  this; if it stops at $800\ \text{mg/cm}^2$ the extrapolation is a long way
  and the uncertainty balloons. Stacking is fine.
- Typical student result: $T_{\max} = 2.1$–$2.5\ \text{MeV}$. Accepted
  $2.280\ \text{MeV}$.
- Relativistic: $\gamma = 5.462$, $\beta = 0.9831$, $pc = 2.744\ \text{MeV}$.
- Classical: $\beta_{\text{cl}} = 2.99$ — nearly $3c$. This is the punchline.
- Air correction: $1.2\ \text{mg/cm}^2$ per cm of gap; with the mica window a
  $3\ \text{cm}$ geometry adds about $5.6\ \text{mg/cm}^2$.

## Where groups get stuck

1. **Counting for a fixed time at every point.** The tail points then carry
   almost no information and the extrapolation is garbage. Enforce the
   increasing-count-time rule at the bench — this is the single biggest
   determinant of whether the experiment works.
2. **Moving the source between points.** Inverse square masquerades as
   absorption. Fix the shelf and say so.
3. **Not taking enough points on the flat tail.** Four minimum; six is better.
4. **Ignoring the $R_0$–$\mu$ correlation** when propagating $\sigma_{R_m}$.
   Almost every group does this the first time; it is a good thing to catch in
   the report and to require in the resubmission.

## Grading notes

- The classical-versus-relativistic comparison should be stated in terms of
  what is wrong with $T = \frac12 mv^2$, not merely that $v > c$ is
  impossible. Question 6 asks exactly this; grade it hard.
- Look for the dead-time discussion. At the no-absorber rate the correction
  can be several percent.
- The difference between the two range–energy relations is a legitimate
  systematic; a report that quotes only one is incomplete.

## Safety

The only unusual element is that the source is out on the bench for the whole
period. Enforce the shelf-stand geometry (which also keeps distance) and check
that it goes back into shielded storage before analysis begins.
